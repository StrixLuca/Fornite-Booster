About this booster

A free Fortnite booster that helps the game run smoother and squeezes out more FPS. It runs on any PC, any graphics card and any processor, from a high end rig to an old laptop. Nothing gets installed and nothing keeps running once you close it.

Everything it does is out in the open. It changes your Fortnite settings and a handful of normal Windows options, and it saves a backup of your config first so you can always roll back. No cheats, no aimbot, nothing gets injected into the game, and it never touches Easy Anti Cheat or BattlEye. Your account stays safe.

Fortnite likes to overwrite your settings every time it starts. To stop that, the booster can lock your config file as read only. While it is locked you change your Fortnite settings right here in the Game Settings tab instead of in game, and they finally stick.

The whole project is open source. If you want to know exactly what a button does, read the code yourself. It is written to be readable on purpose, so you never have to just take our word for it.

What exactly does it change?
Your Fortnite config (shadows, effects, motion blur, render mode, resolution, FPS limit), plus safe Windows options like Game Mode, Hardware Accelerated GPU Scheduling, the power plan, Game DVR, mouse and keyboard responsiveness, and network settings. Every single one is something you could change by hand. All of it is reversible.
Is it safe?
Yes. It only edits config files and Windows settings you already have access to. A backup is made before every boost, everything can be undone, and the full source is public so anyone can check what it does.
